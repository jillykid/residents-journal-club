# Journal Club – ST-läkare i psykiatri, Malmö

Webbplats för journal club: schema, arkiv över artiklar och presentationer, upplägg och tips.

- Data hämtas från Google-arket "Journal Club Database" via Apps Script (se `CONFIG` i `app.js`).
  - **Schema**: Datum, Presentatör, Titel. Skriv "TBA" om artikeln inte är bestämd, "Inställt" om tillfället ställs in, lämna Presentatör tom för ledig plats.
  - **Artiklar och Presentationer**: Datum, Artikeltitel, Länk till artikel, Länk till presentation, Presentatör, Referens.
- Teams-länk: fyll i `teamsURL` i `app.js` så visas knappen "Anslut via Teams".
- Den gamla versionen av sajten finns i `old/`.
